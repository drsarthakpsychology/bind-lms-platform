Note that in each of these examples, a mode/mechanism of harm is coded alongside the
cause of harm code for all cases. This is true, even when a mode of harm is not apparent. In
the latter situations, a code for ‘mode or mechanism of injury unspecified’ should be
selected, for any of substance-related harm, procedure-related harm, or device-related
harm. For the ‘other health care related causes’ the harm should be coded (from anywhere
in the classification) followed by code PL10 Other health care related causes of injury or
harm followed by the appropriate code from category PL14 Mode of injury or harm
associated with other health care related causes (where there are several mode options).
